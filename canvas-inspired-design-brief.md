# CampusFix Light Workspace Design Brief

## Reference observations

The supplied Air Canvas reference uses a deliberately light, expansive workspace rather than a conventional dashboard. The interface relies on a high-key blue-to-white atmosphere, broad calm whitespace, restrained rounded utility controls, small floating agent actions, and a composition that feels like an active working surface rather than a card stack.

## CampusFix translation

CampusFix will not copy Air branding, assets, copy, or page structure. It will translate the useful interaction qualities into an appropriate university-support experience: an ivory and mist-blue working surface, warm apricot and sage status accents, an edge-light utility header, a large conversational work area, a compact ticket/activity dock, and a clear diagnosis rail. The interface will stay light and calm, use only restrained gradients, and avoid dark heavy grading, generic SaaS cards, and decorative excess.

## Interaction principles

The conversation remains the primary work surface. The diagnosis rail should progress visibly but quietly as messages are streamed. Ticket status is event-driven: a raised issue enters Current automatically, and a confirmed resolution moves the same ticket to Resolved while updating the displayed count. Voice selection should be a transparent browser capability setting, with American-English voices grouped by available feminine and masculine voice labels rather than fabricated voice identities.
